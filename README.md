## Project Summary
This project is a hands-on data lab on the Titanic passenger dataset (891 passengers, 15 columns), built in Python with Pandas, NumPy, Matplotlib, and Seaborn. It covers environment setup, data exploration, manipulation (filtering, sorting, grouping, new columns), data cleaning, visualization, and basic analysis, with the results documented in a written report.

## Key Findings
- **Overall survival rate:** about 38% of passengers survived.
- **Gender was the strongest factor:** roughly 74% of women survived compared with about 19% of men.
- **Class mattered:** survival fell from about 63% in 1st class to 47% in 2nd and 24% in 3rd.
- **Fare tracks class:** higher classes paid higher fares, and fare is positively linked to survival.
- **Family size had an effect:** passengers in small families (2 to 4 members) survived more often than those travelling alone or in very large families.

**Conclusion:** gender and socio-economic status (class and fare) were the two dominant factors in survival.
